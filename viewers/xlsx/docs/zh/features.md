# 功能与限制

这是一个早期实现。它**不等同于 Microsoft Excel**，对于模型未覆盖的功能，保存也不是无损的。本页列出编辑器能够处理和无法处理的内容；当工作簿包含不受支持的内容时，编辑器会报告出来（`workbook-warning`），而不是隐藏。

[当前的对等状态与证据](https://github.com/ChristopherVR/ooxml/blob/main/docs/xlsx-parity-status.md)总结了已实现的工作、与原生 Excel 的对比以及剩余的差距。

::: warning 早期版本
`ooxml-core` 中的工作簿引擎和 `<xlsx-editor>` 组件都还很年轻。浏览器测试（`e2e/xlsx/*.spec.ts`）覆盖了打开 `.xlsx`、`.xls` 和 `.csv`、输入值和公式、重新计算、功能区格式设置、插入和删除行、工作表标签、撤销和重做、查找和替换、设置单元格格式、图表选择、保存并重新打开、只读模式、语言区域以及全部六种框架绑定。下面的其余内容虽已实现，但经过的测试较少，可能存在不完善之处。
:::

## 文件格式

| 格式             | 打开 | 保存           | 说明                                                                                                                                                   |
| ---------------- | ---- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `.xlsx`, `.xltx` | 是   | 是             | 主要格式。                                                                                                                                             |
| `.xlsm`          | 是   | 是             | VBA 项目原样保留；宏绝不会运行。                                                                                                                       |
| `.xls` (97-2003) | 是   | 保存为 `.xlsx` | 通过共享的 ole2 编解码器读取：值、可解码的公式、基本格式、合并单元格、列宽、行高、冻结窗格。                                                           |
| `.csv`           | 是   | 是             | RFC 4180，自动检测分隔符；导入时以 = 开头的字段保持为文本。导出写入当前工作表显示的值，并防范公式注入。                                                |
| 受密码保护       | 是   | 是             | 加密的 .xlsx/.xlsm 文件会提示输入密码。“文件 > 信息 > 加密工作簿”为之后的 Excel 保存设置密码。打开加密文件并不会保留其密码用于保存；保存前请重新设置。 |
| `.xlsb`, `.ods`  | 否   | 否             |                                                                                                                                                        |

## 网格与格式

- 单元格值、带富文本片段的共享字符串、布尔值、错误和日期（1900 和 1904 日期系统）。
- 字体、填充（纯色、图案，渐变为近似）、边框、对齐、自动换行、缩进、旋转。
- 数字格式：分节、条件、颜色、日期和时间、分数、科学计数、文本。放不进列宽的 General 数字会减少小数位或切换为科学计数法，其他数字显示为 `###`，均按浏览器的字体测量。
- 编辑后，行高会随换行或放大的文本调整，除非该行设置了自定义高度。
- 合并单元格、列宽和行高、隐藏的行和列、冻结窗格、缩放、网格线。
- 条件格式：单元格规则、文本规则、“发生日期”（今天、最近 7 天、本月等）、前几项和后几项、高于平均值、重复值、色阶、数据条、图标集，并提供可编辑、重新排序和删除规则的规则管理器。
- 数据验证，网格中提供列表下拉。
- 批注（显示、编辑；串联回复显示为注释）、超链接。

## 公式

计算引擎位于 `ooxml-core`，每次编辑后会重新计算依赖单元格。其函数目录包含 497 个函数（2026-10-15 根据 `FUNCTION_CATALOG` 统计），涵盖数学和三角函数、统计（包括反分布以及 `LINEST`、`LOGEST`、`TREND` 和 `GROWTH` 系列）、逻辑、文本（包括 `REGEXTEST`、`REGEXEXTRACT` 和 `REGEXREPLACE`）、日期、查找（包括 `XLOOKUP` 以及 `FILTER`、`SORT`、`UNIQUE` 和 `SEQUENCE` 等动态数组）、信息、财务（包括债券、息票、不规则周期证券函数（`ODDFPRICE`、`ODDFYIELD`、`ODDLPRICE`、`ODDLYIELD`）、贴现证券和国库券函数，以及 `AMORDEGRC`、`VDB` 和 `XIRR`）、工程（包括 `COMPLEX`、`IM` 系列函数、`CONVERT` 和 `BESSEL` 函数）和数据库（`DSUM`、`DCOUNT`、`DGET` 等）。“插入函数”按类别列出这些函数。

并非所有 Excel 函数都存在：未知函数会显示 `#NAME?`。以下函数尚未实现：`FORECAST.ETS`、`ASC`、`DBCS`、`JIS`、`PHONETIC`、`INFO` 和 `WEBSERVICE`。`GETPIVOTDATA` 从缓存记录中读取本编辑器的数据透视表（工作表区域透视表），无法解析的内容返回 `#REF!`。`GROUPBY` 和 `PIVOTBY` 是子集：仅一个聚合函数（`SUM` 或 `PERCENTOF` 等函数名，或 `LAMBDA`），仅总计（总计深度 0、1 或 -1，无分类汇总），字段标题 0、1 或 3，不支持函数数组，输出为重复行标签的扁平分组；`PIVOTBY` 仅接受一个列字段。`TRIMRANGE` 以数组而非引用返回裁剪后的值。`BESSELJ(1.9,2)` 返回精确值 0.3299257277，与 Microsoft 文档中的 0.329925829 不同（Excel 本身在此处约有 1e-7 的偏差）。不规则周期证券函数使用准息票方法，并能重现 Microsoft 的示例；较长的不规则首期尚未与 Excel 核对。外部工作簿引用会保留，但不会解析。

循环引用会被报告，并保持为 0，除非开启了迭代计算。在“文件 > 选项 > 公式”中开启（启用迭代计算，并设置最多迭代次数和最大误差）；该设置随工作簿保存（`calcPr iterate`、`iterateCount`、`iterateDelta`）。之后循环组最多重新计算到最大迭代次数，一旦没有单元格的变化超过最大误差即停止。开启或关闭它不是一个撤销步骤。

计算可以在自动和手动之间切换（“公式 > 计算选项”，或“文件 > 选项”）；该模式随工作簿保存。“立即计算”（F9）和“计算工作表”（Shift+F9）可按需重新计算。“显示公式”（Ctrl+\`）显示公式文本而不是结果。

## 编辑

在单元格中输入（值和公式）、编辑栏和名称框、用 Ctrl+; 和 Ctrl+Shift+; 输入当前日期和时间、填充、复制和粘贴（系统剪贴板支持文本和 HTML）、插入和删除行、列和单元格、排序、筛选、删除重复项、查找和替换、工作表管理（添加、重命名、移动、隐藏、着色；新工作表以界面语言命名，例如德语中的 `Tabelle2`）、内置单元格样式、表格（样式选项、标题行和汇总行、调整大小、转换为区域）、行和列的分级显示组、页面设置和打印选项（网格线、标题、居中）、带有有意义步骤名称的撤销和重做。公式引用会随结构性编辑而更新。

“数据 > 预测 > 模拟分析”有三种工具。**单变量求解**更改一个输入单元格，直到公式单元格达到目标值，并迭代重新计算引擎（最多为工作簿的最大迭代次数，默认 100，直到处于最大误差内，默认 0.001）；“单变量求解状态”对话框点击“确定”保留结果，点击“取消”则还原，整个运行是一个撤销步骤。**数据表**将所选区域转换为单变量或双变量的 `{=TABLE(行输入, 列输入)}` 表：每次计算后，通过把表头的值代入输入单元格来重新计算结果（真正的输入单元格从不更改），该表以 `<f t="dataTable">` 读取和保存，编辑其中一部分会被拒绝（“Cannot change part of a data table.”；选中整个表并清除即可将其删除）。**方案管理器**可添加、编辑、删除和显示方案（每个方案最多 32 个可变单元格，带注释和保护标志），保存为工作表的 `<scenarios>` 元素。未实现：预测工作表（保持禁用并说明原因）、方案管理器的摘要报告和合并、单变量求解的单步和暂停、位于输入单元格所在工作表之外的数据表，以及插入或删除行列时移动数据表。

工作表和工作簿结构保护可以带有密码。它用于防止意外编辑，而不是安全措施。编辑器既读取并校验 Excel 旧版的 16 位哈希，也读取并校验较新的 SHA-512 哈希（还有 SHA-1、SHA-256 和 SHA-384），因此无论文件携带哪种哈希，“撤销工作表保护”和“撤销工作簿保护”都会要求输入密码。在编辑器中设置的密码以旧版哈希写入。如果某个保护使用了核心无法计算的摘要，则任何密码都无法将其解锁。

图片和图表通过单击来选中：可用鼠标移动和调整大小，用方向键微调，用 Delete 删除；选中图表时会显示“图表设计”选项卡。

## 图表与 SmartArt

常见的图表系列（柱形、条形、折线、面积、饼图、圆环图、散点图、气泡图、股价图（最高-最低-收盘和开盘-最高-最低-收盘）和雷达图）、带次坐标轴的条形图/折线图组合，以及瀑布图、直方图、树状图和旭日图（只读，来自其 ChartEx 部分）根据实时值渲染为 SVG。成交量-股价组合图和曲面图显示带标签的框架。图表的插入、类型和分组、标题、图例及颜色更改使用共享核心和 Office 图库控件。停靠式格式设置窗格提供系列填充、受支持的条形间距，以及图表区、绘图区、标题和图例的填充。受支持的渐变类型、渐变光圈、透明度、亮度、方向预览和原生预设共用相同的填充控件。

导入的图表样式、受支持的阴影和渐变、坐标轴可见性、继承的字体、混合格式的标题片段、自动标题换行以及点和百分比标题段落间距均有渲染和保留支持。导入的手动标题位置和标题叠加会被渲染；标题、绘图区、图例的布局 XML 在更改图表类型时会被保留。导入的手动图例矩形和叠加会被渲染，包括经过测试的水平和垂直条目排列。手动标题尺寸、完整的绘图区定位、自动图例几何、多行多列图例排布以及位置编辑控件仍不完整。曲面图不会绘制：它们渲染为带标签的框架，并在保存时保留（`src/core/chart/render/`、`src/core/xlsx/layout/chart.test.ts`）。不支持图表样式的创作：导入的样式定义会被保留和渲染，但无法创建或编辑（`src/core/xlsx/model.ts`、`styleDefinition`）。上述渲染和格式设置由核心的图表测试以及 ooxml 仓库中的 `docs/xlsx-parity-status.md` 覆盖。与原生 Excel 的对比验证了特定的编辑和导出路径。精确的图表文本度量、换行、定位和栅格保真度仍不完整，许多坐标轴、标签和效果控件、高级图表系列以及完整的原生界面也是如此。

SmartArt 使用共享的缓存绘图渲染器，并采用工作簿主题的字体和颜色。它仍然仅用于显示：不支持插入、文本编辑、重排以及完整的布局、颜色和样式图库。缺少缓存绘图时会生成文本占位符。

## 迷你图

Excel 2010 的迷你图绘制在其所在单元格中，位于单元格文本之后：折线（带标记以及最高点、最低点、首点、尾点和负点）、柱形和盈亏。绘制遵循该组关于空单元格（间隙、零或连接）、纵坐标轴（每个迷你图、整个组或自定义范围）、零值处的横坐标轴、日期轴、从右到左绘制、隐藏单元格以及主题色或 RGB 颜色的设置。当其数据区域中的单元格发生变化时，迷你图会重绘，并随其单元格调整大小。迷你图的 XML 按加载时的原样保存，插入或删除行和列时，迷你图会随其单元格移动。

“插入 > 迷你图”根据数据区域和位置区域创建折线、柱形和盈亏组。纵向的位置区域将数据行对应到各个迷你图；横向的位置区域则对应数据列。选中宿主单元格并选择“迷你图设置”，即可更改整个组的类型、标记、系列和负点颜色、线条粗细、空单元格和隐藏单元格的处理、坐标轴可见性、方向，以及各自、共享或自定义的纵向范围。“清除所选迷你图”会移除所选宿主；“清除迷你图组”会移除其整个组。这些更改支持撤销以及保存和加载。

不提供样式图库、分组和取消分组。日期轴可在迷你图设置中打开或关闭。不会匹配 Excel 的精确像素输出（标记大小、柱间距和线条抗锯齿），数据区域中的非数值单元格按空处理。

## 不支持的内容（尽可能保留）

| 功能                          | 行为                                                                                                                                                                                                                                                                                                                                                                              |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 形状、SmartArt、表单控件      | 图片可显示。SmartArt 通过共享渲染器使用缓存绘图（仅显示）；没有缓存绘图时，列出其文本。其他绘图显示为占位符。                                                                                                                                                                                                                                                                     |

核心的往返测试和 Excel 验收检查位于 `ooxml` 仓库。如果某个工作簿渲染或保存有误，请提交 issue，若可以分享文件，请附上该文件。

打开工作簿时会报告数字签名，保存时会将其移除。编辑器不会对文件签名。超链接遵循共享核心的策略；只有网页和电子邮件链接会在外部打开。
