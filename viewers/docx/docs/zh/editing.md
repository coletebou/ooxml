# 编辑文本

所有框架挂载的都是同一个 Web Component 编辑器。命令、键盘快捷键、搜索、语言元数据和文档转换都只有一套实现。

## 查找和替换

编辑器获得焦点时，使用**查找和替换**或 **Ctrl+F**（macOS 上为 **Command+F**）。输入要查找的字面短语，然后使用**查找下一个**或**查找上一个**在匹配项之间移动。**区分大小写**用于控制大小写敏感性。按 Esc 会关闭面板并将焦点返回文档。

搜索可以跨越同一段落内相邻的带格式文本片段，但不会跨段落、表格单元格或硬换行进行匹配。它会避免在 Unicode 字素中间拆分匹配，例如组合序列的一部分或连接的表情符号。搜索是字面匹配；不支持正则表达式和特定语言环境的语言学匹配。

**替换**会更改当前匹配项；**全部替换**会在一次可撤销的操作中更改文档中所有匹配项。替换文本沿用被匹配的第一个字符的格式，匹配范围之外的文本保持其格式。只读模式下可以搜索，但替换被禁用。导出围绕不受支持的源内容所做的编辑时，现有的 DOCX 保真检查依然适用。

## 多语言文档

段落方向和文本语言是相互独立的属性。使用**段落方向**设置从左到右或从右到左的布局，使用**文本方向**在段落内显式覆盖方向。语言控件会存储 Word 的常规、东亚和复杂文种语言标记。语言元数据不会翻译文本，也不会安装拼写检查器。

编辑器会保留 Unicode 文本，包括阿拉伯语、希伯来语、中日韩文字、组合字符和表情符号。屏幕上的显示效果取决于浏览器的字体、字形整形和双向布局。这些控件并不能确立与 Word 等效的复杂文种排版、分页或操作系统输入法的行为。

字数统计使用浏览器的 Unicode 分词，在受支持的情况下，对不使用空格分隔的文字采用词典分词。统计结果可能因 ICU 版本而异，也可能与 Microsoft Word 不同。较旧的浏览器使用精度较低的备用方案。

## 协同编辑集成

[协作指南](/zh/collaboration)介绍了带版本的编辑协议，以及应用如何将共享编辑器连接到其权威端。这是一个集成 API，而不是托管的协作服务。访问控制、网络、存储和重新连接策略由应用负责。

## 界面语言

将共享编辑器的 `locale` 属性（或绑定的 `locale` 属性）设置为 `en`、`fr`、`de`、`es` 或 `zh-CN`。区域和文字变体会解析为最接近的受支持语言（`fr-CA`、`de-DE`、`es-MX`、`zh-Hans`、`zh-SG`）；不受支持的语言环境（包括繁体中文 `zh-TW`、`zh-Hant`）会回退到英语。`EDITOR_LOCALES` 列出了这些代码，`normalizeEditorLocale()` 可将任意标记映射为其中之一。每个语言环境都定义了所有字符串键（在编译时检查，并有测试覆盖）。德语、西班牙语和简体中文的字符串尚未经过母语人士审阅。更改界面语言时，会保留当前文档、选区、撤销历史和文档语言元数据。

## 导入的段落样式

“开始”功能区的样式选择器会列出已加载 DOCX 中的段落样式。编辑器通过文档默认值和所选样式的继承链来解析受支持的对齐、方向、间距和缩进。直接段落格式仍然优先。选择样式只会更改其引用，而不会把继承的属性展平到每个段落中。

保存已加载的文档时，会保留原始的样式部件。目前尚不支持创建或编辑样式定义、字符样式、继承的文本格式以及主题解析。导出样式目录与内置默认值不同的新包会被拒绝；请对已加载的文档使用“保存”，以保留其原始样式定义。
