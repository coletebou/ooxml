# Atajos de teclado

En macOS, use **Cmd** donde se indica **Ctrl**.

::: info Los atajos dependen del contexto
Los atajos de edición solo funcionan en modo de edición y se suprimen mientras escribe en un cuadro de texto, edita una celda de tabla o usa una herramienta de la pestaña Dibujar, de modo que las teclas van al texto. Los atajos de la presentación solo funcionan mientras presenta, salvo **F5** / **Mayús+F5**, que la inician. **Escape** siempre funciona.
:::

::: tip Referencia en la aplicación
Dentro de la aplicación hay disponible una lista abreviada de atajos: **pestaña Ayuda > Atajos de teclado**, o **Atajos de teclado** en el menú de desbordamiento **"..."**.
:::

## Edición

Activos en modo de edición cuando no está escribiendo en un elemento.

| Acción                                            | Atajo                         |
| ------------------------------------------------- | ----------------------------- |
| Deshacer                                          | **Ctrl+Z**                    |
| Rehacer                                           | **Ctrl+Mayús+Z** o **Ctrl+Y** |
| Copiar el elemento seleccionado                   | **Ctrl+C**                    |
| Cortar el elemento seleccionado                   | **Ctrl+X**                    |
| Pegar elemento                                    | **Ctrl+V**                    |
| Duplicar el elemento seleccionado                 | **Ctrl+D**                    |
| Eliminar el elemento seleccionado                 | **Supr** o **Retroceso**      |
| Seleccionar todos los elementos de la diapositiva | **Ctrl+A**                    |
| Desplazar el elemento seleccionado                | **Teclas de flecha**          |
| Desplazar el elemento seleccionado (paso mayor)   | **Mayús+Teclas de flecha**    |
| Agrupar los elementos seleccionados               | **Ctrl+G**                    |
| Desagrupar los elementos seleccionados            | **Ctrl+Mayús+G**              |
| Abrir o cerrar Buscar y reemplazar                | **Ctrl+F**                    |
| Abrir o cerrar este panel de atajos               | **?** o **Ctrl+/**            |
| Anular selección / cerrar menús / dejar de editar | **Escape**                    |

**Ctrl+F** es el único atajo que sigue funcionando mientras escribe dentro de un
elemento, igual que en PowerPoint: es el atajo al que se recurre con el
cursor ya dentro de un cuadro de texto.

## Edición de texto

Mientras escribe dentro de un elemento.

| Acción                         | Atajo          |
| ------------------------------ | -------------- |
| Confirmar la edición del texto | **Ctrl+Intro** |
| Cancelar la edición del texto  | **Escape**     |

## Navegación y vista

| Acción                                    | Atajo                    |
| ----------------------------------------- | ------------------------ |
| Diapositiva anterior (nada seleccionado)  | **Flecha izquierda**     |
| Diapositiva siguiente (nada seleccionado) | **Flecha derecha**       |
| Acercar / alejar el lienzo                | **Ctrl+Rueda del ratón** |

Acercar, alejar y ajustar a la ventana también son botones de la barra de estado.

::: tip
Las teclas de flecha tienen doble función en modo de edición: con un elemento seleccionado lo desplazan; sin nada seleccionado cambian de diapositiva.
:::

## Clasificador de diapositivas

Activos mientras la superposición del clasificador de diapositivas está abierta.

| Acción                                               | Atajo                    |
| ---------------------------------------------------- | ------------------------ |
| Copiar las diapositivas seleccionadas                | **Ctrl+C**               |
| Pegar diapositivas                                   | **Ctrl+V**               |
| Duplicar las diapositivas seleccionadas              | **Ctrl+D**               |
| Seleccionar todas las diapositivas                   | **Ctrl+A**               |
| Eliminar las diapositivas seleccionadas              | **Supr** o **Retroceso** |
| Acercar / alejar las miniaturas                      | **Ctrl +** / **Ctrl -**  |
| Contraer la selección y luego cerrar el clasificador | **Escape**               |

::: info No todos los clasificadores tienen todos los comandos
Los cinco visualizadores responden a **Escape**, **Supr** y **Ctrl+D** en el clasificador. El portapapeles de diapositivas
(**Ctrl+C** / **Ctrl+V**), **Ctrl+A** y las teclas de zoom de miniaturas necesitan un clasificador con
multiselección y zoom, que por ahora solo incluye el visualizador React; en los demás esas combinaciones pasan al
navegador en lugar de no hacer nada en silencio.
:::

## Presentación con diapositivas

Iniciar la presentación funciona desde cualquier punto del visualizador, incluso mientras escribe y
también en un visualizador de solo lectura; el resto solo están activos mientras presenta.

| Acción                                         | Atajo        |
| ---------------------------------------------- | ------------ |
| Iniciar la presentación desde el principio     | **F5**       |
| Iniciar la presentación desde esta diapositiva | **Mayús+F5** |

::: warning F5 ya no recarga la página mientras el visualizador tiene el foco
Son las teclas de PowerPoint, y también la tecla de recarga del navegador. El visualizador reclama un **F5** simple
solo cuando el foco del teclado está dentro de él y no hay ninguna presentación en curso; **Ctrl+F5** y el botón
de recarga del navegador no se tocan.
:::

Coinciden con las teclas de presentación del propio PowerPoint. Tenga en cuenta la división deliberada: las
herramientas de anotación son combinaciones con **Ctrl**, porque PowerPoint reserva las letras sueltas `N`, `P`, `B`, `W`
y `E` para la navegación y los comandos de pantalla.

| Acción                                                        | Atajo                                                                                      |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Diapositiva siguiente / siguiente paso de animación           | **Flecha derecha**, **Flecha abajo**, **Av Pág**, **Barra espaciadora**, **Intro** o **N** |
| Diapositiva anterior                                          | **Flecha izquierda**, **Flecha arriba**, **Re Pág**, **Retroceso** o **P**                 |
| Primera diapositiva                                           | **Inicio**                                                                                 |
| Última diapositiva                                            | **Fin**                                                                                    |
| Saltar a una diapositiva                                      | Escriba su número y luego **Intro**                                                        |
| Pantalla en negro activada / desactivada                      | **B** o **.**                                                                              |
| Pantalla en blanco activada / desactivada                     | **W** o **,**                                                                              |
| Puntero de flecha (normal)                                    | **Ctrl+A**                                                                                 |
| Puntero láser                                                 | **Ctrl+L**                                                                                 |
| Lápiz                                                         | **Ctrl+P**                                                                                 |
| Borrador                                                      | **Ctrl+E**                                                                                 |
| Borrar todas las anotaciones de una diapositiva               | **E**                                                                                      |
| Mostrar / ocultar las marcas de tinta                         | **Ctrl+M**                                                                                 |
| Mostrar / ocultar la barra de herramientas de la presentación | **Ctrl+H**                                                                                 |
| Mostrar todas las diapositivas                                | **Ctrl+S**                                                                                 |
| Subtítulos en vivo activados / desactivados                   | **J**                                                                                      |
| Menú contextual de la presentación                            | **Mayús+F10** o la tecla **Menú**                                                          |
| Terminar la presentación                                      | **Escape** o **-**                                                                         |

::: info Cobertura de las dos combinaciones de la interfaz
**Ctrl+H** (ocultar la barra de herramientas de la presentación) y **Ctrl+S** (Mostrar todas las diapositivas) las reconoce el
mapa de teclas de presentación compartido y las gestiona cada visualizador.
:::

El resaltador no tiene atajo de teclado; use la barra de herramientas de la presentación. La vista del presentador también es un
interruptor de la barra de herramientas, no una tecla. Consulte [Presentar](/es/user/presenting) para saber cómo funcionan las herramientas
de anotación y la vista del presentador.
