# Affichage des présentations

Cette page couvre la lecture d'une présentation : se déplacer entre les diapositives, zoomer, les diapositives masquées et les notes du présentateur. Pour savoir comment ouvrir un fichier en premier lieu, voir [Ouvrir un fichier](/fr/user/#ouvrir-un-fichier).

Une fois le fichier chargé, la diapositive active s'affiche sur le **canevas de diapositive** au centre, avec une bande de vignettes dans le **panneau des diapositives** à gauche.

![Canevas de diapositive affichant une présentation chargée](/user-guide/viewing-slide-canvas.jpg)

Les graphiques, tableaux, formes, SmartArt et médias s'affichent tous en contenu vivant ; vous pouvez donc sélectionner du texte sur la diapositive et le copier comme sur n'importe quelle page web.

![Un graphique affiché sur une diapositive](/docs-shots/chart-slide.jpg)

## Naviguer dans les diapositives

Passez d'une diapositive à l'autre de l'une de ces façons :

- **Panneau des diapositives** - cliquez sur une vignette à gauche pour accéder directement à cette diapositive.
- **Touches fléchées** - avec rien de sélectionné sur le canevas, appuyez sur **Flèche gauche** / **Flèche droite** pour passer à la diapositive précédente / suivante.
- **Barre d'état** - le compteur en bas à gauche indique **Diapositive x sur y**, pour savoir toujours où vous en êtes.

![Navigation entre les diapositives](/user-guide/viewing-navigation.gif)

Le panneau des diapositives met en évidence la diapositive en cours par une barre colorée sur son bord gauche.

::: tip Les touches fléchées ont une double fonction
En mode édition, les touches fléchées déplacent légèrement l'élément sélectionné. Elles ne changent de diapositive que si rien n'est sélectionné. Appuyez d'abord sur **Échap** pour désélectionner.
:::

## Zoom et ajustement

Les commandes de zoom se trouvent à l'extrémité droite de la **barre d'état** :

| Commande                        | Ce qu'elle fait                                                                                                |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Zoom arrière** (bouton moins) | Diminue le zoom par paliers.                                                                                   |
| **Bouton de pourcentage**       | Affiche le niveau de zoom actuel ; cliquez dessus pour **ajuster à la fenêtre** la zone de canevas disponible. |
| **Zoom avant** (bouton plus)    | Augmente le zoom par paliers.                                                                                  |

![Commandes de zoom dans la barre d'état](/user-guide/viewing-status-bar.jpg)

Vous pouvez aussi :

- Maintenir **Ctrl** (Cmd sur macOS) et faire défiler la molette de la souris sur le canevas pour zoomer en douceur autour du pointeur.
- Utiliser **onglet Affichage > Ajuster à la fenêtre** dans le ruban.
- Pincer pour zoomer sur les appareils tactiles.

## Modes d'affichage

La barre d'état comporte trois boutons d'affichage :

- **Affichage normal** - la disposition standard avec le panneau des diapositives, le canevas et l'inspecteur.
- **Trieuse de diapositives** - une grille plein écran de toutes les diapositives.
- **Diaporama** - lance une présentation en plein écran (voir [Présentation](/fr/user/presenting)).

### La trieuse de diapositives

La trieuse de diapositives est le meilleur moyen d'avoir une vue d'ensemble d'une grande présentation :

1. Cliquez sur **Trieuse de diapositives** dans la barre d'état.
2. Parcourez la grille. Lorsque la présentation comporte des sections, les diapositives sont regroupées sous les titres de leur section.
3. **Double-cliquez** sur une diapositive pour l'ouvrir en affichage normal, ou appuyez sur **Échap** pour fermer la trieuse.

Dans la trieuse, vous pouvez aussi :

- Faire glisser les diapositives pour les réorganiser (mode édition).
- Cliquer pour sélectionner, **Maj-clic** pour sélectionner une plage, et clic droit pour les actions sur les diapositives (dupliquer, masquer, supprimer ; voir [Gérer les diapositives](/fr/user/editing#gerer-les-diapositives)).
- Zoomer sur les vignettes avec le curseur de la barre d'outils inférieure, ou appuyer sur **Ctrl +** / **Ctrl -**.

## Diapositives masquées

Les diapositives marquées comme masquées restent dans le fichier mais sont ignorées pendant un diaporama.

- Dans le panneau des diapositives et la trieuse, elles apparaissent estompées, avec des hachures diagonales et une icône d'œil barré.
- Vous pouvez toujours ouvrir, lire et modifier normalement une diapositive masquée.
- Pour masquer ou afficher des diapositives, faites un clic droit dessus dans la trieuse et choisissez **Masquer les diapositives** ou **Afficher les diapositives** (mode édition).

## Lire les notes du présentateur

1. Cliquez sur le bouton **Notes** de la barre d'état pour ouvrir le panneau de notes sous le canevas.
2. Les notes du présentateur de la diapositive en cours s'y affichent ; faites défiler si elles sont longues.
3. Cliquez de nouveau sur **Notes** pour fermer le panneau.

Pendant un diaporama, les notes vous sont montrées (et non au public) dans la **vue du présentateur** ; voir [Présentation](/fr/user/presenting#vue-du-presentateur).
