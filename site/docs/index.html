Open OOXML Office

Documentation

OOXML Office is a set of Office editors that run in the browser: Word, Excel, PowerPoint and Visio files, plus a team workspace and a notebook. There are three ways in. Use the apps as they are, embed one editor in your own site, or build on the library underneath them.

Use the appsOpen a file and work on it. No account, nothing leaves your device. Embed an editorAdd Word, Excel, PowerPoint, Visio or Teams to a React, Vue, Angular, Svelte, Solid or plain page. Build on the libraryRead, change and write the files from code, with no UI, or drive them from an agent.
